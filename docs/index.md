# claude-extras

A drop-in `claude` that routes each project directory to its own Claude Code
account, and looks across every account where the official CLI sees one.

[Installation](install.md) is two commands and how to undo them.
[Accounts](accounts.md) covers logging a project in to an account and the doctor.
[Commands](commands.md) takes each verb in turn, with where its numbers come from,
and [Architecture](architecture.md) is how a launch resolves and where every file
lives. The [README](https://github.com/maximdeclercq/claude-extras) is the short
version.
